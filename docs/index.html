01 What you get

Everything a dashboard should be — nothing it shouldn't.

Built around one idea: your dashboard, your rules. No forced layout, no subscription, no telemetry.

  1. 01

    Seventeen widget types

    Tasks & habits, rich notes, calendar, a spreadsheet with real formulas, drawboard, a PDF/EPUB reader with its own bookshelf, charts, weather, map, clock, timer, water & sleep tracking, agenda, quicklinks, images and a sandboxed HTML widget.

  2. 02

    Twenty themes, endless styling

    From Deep Space to Soft Light, every theme ships its own accent colors and background pattern. Style any widget individually on top — color, gradient, border, shadow, glow.

  3. 03

    An assistant, on your own key

    Connect your own Anthropic, OpenAI, Gemini or any OpenAI-compatible key. The assistant builds and edits boards with you, or works scoped to a single widget. Entirely optional.

  4. 04

    Desktop apps that update themselves

    Native builds for Windows, macOS and Linux with automatic background updates — or use it straight in the browser, no install required.

  5. 05

    Genuinely local-first

    Boards, widgets and settings live in IndexedDB on your device. There is no mosaic server — self-host it, run it offline, export a full JSON backup anytime.

  6. 06

    Bilingual, with undo everywhere

    Full English and German interface, proper undo/redo, board templates, folders, and search across every widget on a board.

03 Details

The things you only notice once you live in it.

  1. 01

    Reader ↔ Note highlight linking

    Highlight text in any book in the reader's library, link it into any Note widget as a colored reference — click it later and the reader jumps straight back to that book, page, or location. Progress and highlights save automatically, per book.

  2. 02

    Move or copy a widget to another board

    Every widget's toolbar can send it to a different board instantly — pick from a searchable list, size and style intact. No dragging across two windows.

  3. 03

    Map markers and hand-drawn routes

    Drop colored, labeled pins anywhere, or click out a route point by point with live running distance. Routes are your own waypoints, not an auto-routed path.

  4. 04

    Per-widget AI chat, hard-scoped

    Pin a mini AI chat to a single widget and it is enforced in code to only touch that widget's id — not a prompt suggestion, a hard rule the assistant can't break.

  5. 05

    Focus mode is a real 1:1 mirror

    Double-click any widget and it's the exact same component, scaled up — not a preview. Check off a task or drag a calendar event full-screen, fully interactive.

  6. 06

    A minimap that zooms with you

    Instead of a static fit-to-bounds overview, the live minimap scales in lockstep with your actual board zoom — like radar, not a thumbnail.

  7. 07

    Real spreadsheet formulas, safely evaluated

    =SUM(), IF, COUNTIF and 40+ more, backed by a hand-written parser — no eval, safe to open boards you didn't build yourself.

  8. 08

    Themes as editable JSON, migrated smartly

    Write your own theme as JSON with live validation. Switching themes only replaces widget styles that matched the old theme's defaults — your manual tweaks stay put.

  9. 09

    Reminders that check your actual progress

    Water reminders stop once you've hit today's goal; the sleep reminder only fires if you haven't logged a bedtime yet. Runs in the background, any board.

  10. 10

    An HTML widget that needs no hosting

    Paste or upload a self-contained .html file and it renders live in a sandboxed iframe — no URL, no server, no install step. Flip to a code view anytime to see or edit the source, or hit reload to restart it.

  11. 11

    Pin a widget to your real desktop

    Detach any widget into its own small, always-on-top window right on your desktop — a task list or clock outside the app entirely. Still fully live: check something off there and the board updates instantly, not a static snapshot.

Installation notes — what the security warnings mean
Windows — "unknown publisher" warning +

SmartScreen will warn about an unsigned build the first time you launch it — that's expected, not a broken download.

Click "More info" → "Run anyway". It won't ask again after that.

macOS — "mosaic is damaged" message +

You'll likely see "'mosaic' is damaged and can't be opened. You should move it to the Trash." That's just Gatekeeper's generic warning for any app without a paid Developer ID signature — the download itself isn't broken, and right-click → "Open" no longer bypasses it on current macOS. Two steps fix it:

  1. Move mosaic.app into /Applications. (Finder shows this folder under your system's language — e.g. "Programme" on a German Mac — but the actual path on disk is always /Applications, in every language.)
  2. Run this once in Terminal: 
    xattr -cr /Applications/mosaic.app
Linux — terminal install, no version to edit +

Only .deb and .AppImage are published. Each command looks up the current release itself via the GitHub API — works the same in bash, zsh, and fish.

Debian-based — Debian, Ubuntu, Mint, Pop!_OS, elementary OS 
curl -s https://api.github.com/repos/Aetherion7/mosaic/releases/latest | grep browser_download_url | grep '\.deb"' | cut -d '"' -f4 \
  | xargs -I{} sh -c 'wget "$1" && sudo apt install "./$(basename "$1")"' _ {}
Arch-based — Arch, Manjaro, EndeavourOS, CachyOS 
sudo pacman -S --needed fuse2
curl -s https://api.github.com/repos/Aetherion7/mosaic/releases/latest | grep browser_download_url | grep '\.AppImage"' | cut -d '"' -f4 \
  | xargs -I{} sh -c 'wget "$1" && chmod +x "$(basename "$1")" && "./$(basename "$1")"' _ {}
Fedora-based — Fedora, Nobara, RHEL 
sudo dnf install -y fuse
curl -s https://api.github.com/repos/Aetherion7/mosaic/releases/latest | grep browser_download_url | grep '\.AppImage"' | cut -d '"' -f4 \
  | xargs -I{} sh -c 'wget "$1" && chmod +x "$(basename "$1")" && "./$(basename "$1")"' _ {}

Any other distro (openSUSE, NixOS, ...): install a fuse2 / libfuse2 compat package if it's missing, then run the same .AppImage command above.

Prefer no install at all? +

Clone the repository and run this — mosaic works entirely in the browser, nothing to package or sign:

npm install && npm run dev
06 Privacy

Local by default, honest about the exceptions.

No tracking, no analytics, no ads — ever. Here is exactly what stays on your device and what doesn't.

Always local

  • Boards, widgets and layout (IndexedDB)
  • Settings, themes, your AI API key if you set one (localStorage)
  • Files and images you add to widgets
  • Works fully offline for all of the above

Only when you use them

  • Map & weather widgets — OpenStreetMap / Open-Meteo
  • Quicklinks widget — favicon lookup via DuckDuckGo
  • AI assistant, if enabled — your chosen provider only
  • HTML widget — sandboxed; whatever the pasted page does is its own doing
  • None of it passes through a mosaic server, because none exists
